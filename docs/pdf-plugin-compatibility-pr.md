## 修改目标

修复 Ink Notes 自动接管 PDF 时使其他插件失去原生 PDF 视图、文字层、工具栏和导航状态的问题，保护跨插件视图切换和原 PDF 外部修改时的笔迹数据。

## 修改内容

- 固定官方 8,635 项目录和 283 个候选仓库提交，提供逐项清单、源码证据、审计报告和可重复收集工具。
- 按源码确认的 49 个原生依赖插件动态让出普通 PDF 打开；额外 persistent / ephemeral 状态原样交给原生视图。
- 补齐 PDF 文件右键手写入口；交还原生标签时保存笔迹、保留源页码及原生标签选择。
- 活动笔画完成后才卸载保存，修复保存和合并期间发生新编辑被标记为已保存的问题。
- 外部 PDF 修改时核对 fingerprint；导出再次核对，防止旧坐标应用到新源文件。
- 重新生成 main.js / main.js.map；增加相应宿主契约及数据回归。

## 不包含的内容

不合并各插件笔迹格式，不实现原生 PDF.js 私有对象兼容层，不修改第三方插件、依赖、门禁或 Vault 数据；不声明全部 283 项已真实联合安装验证，不创建新版本或自动发布。

## 风险等级

中：共享打开路由、保存及导出行为变化。真实宿主插件组合和移动端仍需联调。

## 行为变化

启用已知原生依赖插件时普通 PDF 打开保持原生；手写功能通过命令和右键菜单继续完整可用。页码/区域/搜索/未知导航状态不会丢弃。来源 PDF 改变时旧笔迹保留但编辑/错位导出受阻，需要重新打开复核。

## 验证方式

`npm test -- --exclude '.tmp/**'`：487 项通过；`npm run typecheck`、`npm run build` 通过；58 项浏览器回归通过。新增回归覆盖导航透传、动态启停、右键入口、wrapper 链、活动笔画卸载、保存失败、关闭 recovery copy、并发保存/合并和 fingerprint 保护。真实第三方安装组合、WebKit/Android 和同步服务未验证。

## 性能 / 成本影响

无新增轮询、渲染或常驻网络请求。导出和来源 PDF 修改时增加 SHA-256/字节数检查；大文件性能需实机测试。开发用公开仓库收集工具不进入运行时插件。

## 安全影响

不执行外部插件源码，不读取用户 Vault 或不相关凭据，不修改源 PDF、权限或安全门禁。收集器限制网络等待和源码文件数，并检查缓存路径边界。失败保存显式报错，关闭时另存 recovery copy；存储彻底不可用时不能承诺最新笔迹落盘，原已保存文件不被删除。

## 发布方式

建议 PATCH，当前 metadata 保持 beta.36。任务 PR → master 全部门禁 → release PR 全部门禁 → release 干净构建 → annotated tag → tag 构建 → GitHub Release。须完成真实宿主重点组合验证后晋级。

## 回滚方式

通过 PR revert 本任务提交，包含源码及构建 bundle。没有数据格式迁移，不删除笔迹文件。
