# Unify pen, finger and object gestures across Ink and PDF

## 修改目标

解决图片必须换工具、手指不能框选、长按直接删除以及无笔设备无法书写的手势冲突。默认用笔书写、用手指操作对象和视口；为无笔用户提供明确的全局开关。

## 修改内容

- 共用 Ink/PDF 输入路径处理手指框选和拖动；图片默认允许各工具下手指选中、拖动和等比缩放，Pointer 支持笔或鼠标精确操作。
- 新增持久化 Use finger as pen 设置，默认关闭；启用后单指执行当前笔/荧光笔/橡皮擦/框选工具，双指操作视口，Pointer 单指操作图片/翻页。
- 第二指、系统取消或笔接管撤销未完成的手指编辑，使用现有可逆命令同步模型、Worker 和瓦片并保留撤销/重做历史。
- 600 ms 长按显示剪贴板操作；开启手指书写也能使用，不留下笔迹或擦除。桌面右键提供对应菜单。
- 色板长按显示明确删除菜单，保留原生双击选色；压力曲线改为选点后明确删除，去掉双击/拖到底部删点。
- README 和完整手势矩阵记录操作规则、官方参考、测试边界和便利贴待对齐问题；更新构建产物。

## 不包含的内容

不合并便利贴 PR #177，不调整 PDF 接管、存储格式或依赖，不直接创建 GitHub Release。无新增系统级双指撤销、三指剪贴板或页面双击快捷操作。

## 风险等级

中：涉及触摸事件归属和手势取消。默认手指不写字；可选手指书写需用户明确开启。实机 iPad Pencil/Scribble 和 Android 尚未验证。

## 行为变化

默认在 Pen 下手指拖图片会移动图片，笔触图片仍会写字。Select 下手指可圈选/框选并移动已有笔迹。Pointer 下笔可以操作图片。长按色板或双击曲线点不会直接删除。取消手指擦除采用已有协作恢复规则，等价笔迹会使用新 ID 和墓碑。

## 验证方式

- Vitest：28 文件、628 项通过，含两种视图共用触摸合约、设置持久化/即时生效、笔/手指流去重、取消和历史、长按、只读保护。
- Chromium：43 个不同浏览器用例通过，覆盖图片库/图片操作、框选、原生触摸、色板/曲线、桌面输入、快速翻页、阅读模式、缩放锁定；最新统一手势 4 项复验通过。
- TypeScript 类型检查、生产构建和 git diff --check 通过。人工查看浏览器截图，图片手柄和控件可见。
- 未验证：实际 iPad/Android 硬件、iPadOS Pencil/Scribble/系统掌触识别，Qodana/远程 CI。

## 性能 / 成本影响

复用已有输入、图片几何、长按和可逆命令。单指移动无新增全页缓存、网络请求或定时轮询。双指接管会提交并反向执行本次未完成编辑，使用既有 Worker patch；复杂页面的实机延迟未测量。

## 安全影响

无新增网络访问、权限或依赖。读取旧配置时严格校验布尔开关；阅读模式和 PDF 源变化编辑锁继续有效。删除颜色/曲线点需明确动作。
